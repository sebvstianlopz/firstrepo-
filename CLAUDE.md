# Project instructions

## Project goal
Fully automate entries and exits for futures/options on TradingView.

## Focus
- All code is Pine Script (latest version)
- Follow the rules in docs/rules.md exactly; don't invent new signals
- Every strategy change must be backtested before it counts as done

## Rules
- Never put API keys or account info in the code
- Explain changes in plain language, the owner is not a programmer
- Ask before changing risk settings (stop-loss, position size)
