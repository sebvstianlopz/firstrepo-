# Project: TradingView Pine Script Indicators

This repo is for building trading indicators for TradingView using Pine Script.

## Rules for Claude

1. **Pine Script v6 only.** Every script starts with `//@version=6`. Never use v5 or older syntax.
2. **Always give the full script.** When suggesting changes, output the complete, final Pine Script — never just the changed snippet.
3. **Always use a code block.** Put the code in a fenced code block (```pinescript) so it can be copied directly into the TradingView Pine Editor.
